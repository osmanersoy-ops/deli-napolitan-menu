🔑 GitHub Canlı Yayın Ayarları

"Yayınla" butonuna bastığınızda menüdeki değişikliklerin ve fotoğrafların doğrudan GitHub'a aktarılması ve Vercel üzerinden anında canlıya geçmesi için GitHub Token gereklidir.

Bu anahtar sadece kendi tarayıcınızda (localStorage) güvenle saklanır.
30 Saniyede Nasıl Alınır?
  1. GitHub hesabınıza giriş yapın: github.com/settings/tokens
  2. "Generate new token (classic)" butonuna tıklayın.
  3. Note kısmına Deli Napolitan Admin yazın ve repo kutucuğunu işaretleyin.
  4. En alttan "Generate token"a basıp çıkan kodu buraya yapıştırın.
